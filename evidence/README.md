# Measured research evidence

Generated by `tools/run_study.py` in an isolated, read-only verification container using the pinned Python image. These files describe the reference-model implementation and local mock backend, not deployed cloud providers.

- [summary.json](summary.json): actual counts, runtime, isolation checks and scope.
- [results.csv](results.csv): one row per synthetic fixture.
- [graph-results.json](graph-results.json): complete rule/precondition decision traces.
- [runtime-results.json](runtime-results.json): deterministic synthetic direct-read/job/output audit traces.
- [tests.txt](tests.txt): unique regression test methods and subtest execution.
- [source-manifest.json](source-manifest.json): SHA-256 of source inputs, excluding this evidence directory and caches.

Source inputs must still match the manifest before publication. The graph/runtime result files are deterministic for unchanged inputs; summary timestamps can differ. [Study limitations](../studies/001-ai-infrastructure-authority-bindings/LIMITATIONS.md).
