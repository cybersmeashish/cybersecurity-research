A cloud logging disablement has an explicit unapproved-change context.

**Telemetry:** cloud-aws, cloud-azure, cloud-gcp. **Baseline required:** False. **Temporal association:** False.

**Selected technique context:** No exact ATT&CK mapping asserted. Mapping depends on actual observed behavior; this is not adversary attribution.
