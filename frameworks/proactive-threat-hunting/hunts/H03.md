# H03: Failure burst followed by new-device success

## Hypothesis

Authentication failures followed by first-observed device success warrant identity validation.

**Telemetry:** identity. **Baseline required:** True. **Temporal association:** True.

**Selected technique context:** T1078. Mapping depends on actual observed behavior; this is not adversary attribution.

## Execute

Use the [tested local SQL](../queries/H03.sql) with this framework's normalized schema and [lab runner](../lab/README.md). No native SIEM/provider query is claimed validated. Field requirements are in [hunt-pack.json](../hunt-pack.json).

## Corroborate

Session/device authentication, MFA details, conditional-access result, user confirmation and downstream activity.

## Benign alternatives

Password mistakes, device enrollment, VPN changes or helpdesk-assisted recovery.

Record raw evidence references, source health, identity/tenant boundaries, baseline scope, alternative explanations and analyst confidence. Escalate corroborated leads through the incident process; absence of a result is limited to observed data. Missing coverage yields an inconclusive assessment.
