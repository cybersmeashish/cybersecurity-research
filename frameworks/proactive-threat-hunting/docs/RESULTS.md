# Measured reference results

The isolated first run passed 34 synthetic scenarios: 17 seeded candidates and 17 benign/broken-chain comparisons. The combined demo produced 17 candidate leads across 17 procedures. Nineteen regression methods passed, including tenant/identity joins, scoped deduplication, conflicts, stale/missing collectors, missing authorization mappings, expiry/revocation, baseline isolation, timing and query-path restrictions.

Final generated counts and runtime are in [summary.json](../evidence/summary.json). This is consistency/security-boundary evidence for this source-defined model. It is not operational precision/recall, a real-world false-positive benchmark or a confirmed incident record.
